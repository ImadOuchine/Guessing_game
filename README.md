# Guessing Game

A Python terminal-based guessing game where the player can choose between different game modes and try to find the secret answer.

## Game Modes

The game currently includes:

- Number Guessing — Guess a randomly generated number.
- Car Guessing — Guess the name of a randomly selected car.
- Animal Guessing — Guess the name of a randomly selected animal.

## Features

- Randomly generated numbers, cars, and animals
- Hint system for cars and animals
- Four hints available for each car and animal
- Limited attempts
- Win and lose system
- Input validation with exception handling
- Object-Oriented Programming using a `Hints` class
- Multiple game modes
- Exit option
